# 文学天气（Literary Weather）

一个将气候意象、经典文学人物与人格颜色结合起来的浏览器互动测试。

## 在线体验

- Cloudflare：<https://aged-paper-2292.weatherstudio.workers.dev>

## 产品结构

- 8 种文学气候带
- 16 位中外文学人物
- 题目参考四组人格倾向进行区分，但不提供医学或心理诊断
- 生成文学天气、人物气质、人格颜色与艺术 ID
- 所有计算均在浏览器本地完成，不收集用户输入

## 技术实现

- HTML5
- CSS3
- 原生 JavaScript
- Canvas（生成可保存的结果卡片）

无需安装依赖或构建工具。打开 `index.html` 即可本地运行，也可直接部署到 GitHub Pages、Cloudflare Workers / Pages 等静态托管平台。

## 文件说明

- `index.html`：首页
- `create.html`：测试与结果页
- `css/`：视觉样式
- `js/`：交互、计分和结果卡片生成
- `assets/`：页面图片素材

## 隐私说明

本项目为前端静态演示，不含登录、数据库、付费或后端接口。测试答案仅保存在当前浏览器页面生命周期中。

## 作品说明

本仓库用于作品集展示。文学角色及作品名称用于评论、研究与创意测试语境；结果文案为项目原创或明确标注来源。
